# 用 Suno 生成真人感人聲：13 種節奏型的歌詞與提示詞

整理日期：2026-11-10 ・ 分類：音樂分析 / 節奏感訓練

## 使用方法
1. 打開 Suno，選 **Custom（自訂）** 模式。
2. 把下面每首的「Style」貼進 Style of Music 欄位，「Lyrics」貼進歌詞欄位。
3. 先生成一次，用練習頁對照節奏。Suno 不保證完全照格子譜唱，如果差很多，可以把 BPM 寫得更明確，或多生成幾次挑最接近的版本。

歌詞後面括號裡的數字，是對應練習頁上的節奏型編號。

---
